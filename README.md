# Catan Web

Спільний проєкт 2D вебгри Catan на 3–4 гравців.

## Робота з репозиторієм

Кожен працює у своїй постійній гілці. Про роботу домовляємося в чаті.

| Гілка | Хто працює |
| --- | --- |
| `main` | Спільна версія, куди додаємо готові зміни через pull request |
| `yulian` | Юліан |
| `maksym` | Максим |
| `yura` | Юра |
| `sasha` | Саша |

Гілки не обмежують доступ до файлів: кожен може змінювати потрібну частину проєкту.

## Перший запуск

Приклад для гілки `yulian`; інші учасники підставляють назву своєї гілки.

```sh
git clone https://github.com/ButaFor/catan-web.git
cd catan-web
git switch yulian
```

Після внесення змін:

```sh
git add README.md
git commit -m "Describe the change"
git push
```

Замість `README.md` вказуйте файли своєї задачі.
Коли зміни готові, на GitHub відкрийте **Pull requests → New pull request**:
базова гілка — `main`, гілка зі змінами — ваша. Коротко опишіть зміни.
Після перегляду іншим учасником зливайте через **Create a merge commit**.
Постійну гілку після злиття не видаляйте.

## Отримання спільних змін

Перед подальшою роботою закомітьте свої поточні зміни та, залишаючись у своїй гілці,
виконайте:

```sh
git pull --ff-only
git fetch origin
git merge origin/main
git push
```

Якщо Git повідомить про конфлікт, узгодьте зміни з автором у чаті,
виправте відповідні файли, додайте їх через `git add`, виконайте `git commit`
та `git push`.

Паролі, ключі та файли `.env` у репозиторій не додаємо.
